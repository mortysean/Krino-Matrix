# Krino Matrix

<details open>
<summary><b>English</b></summary>

Krino Matrix aims to free up human cognitive resources.

By using AI to understand complex states, generate feasible options, and evaluate the value of actions, we reduce the cognitive burden of processing information, analyzing, and making decisions — so everyone can devote their limited attention to more creative and meaningful work.

### Core Concepts

| Module | Role |
| --- | --- |
| `State` | Describes the current situation |
| `Generator` | Generates candidate actions from a state and an objective |
| `Evaluator` | Scores how valuable an action is |
| `Decision` | The chosen action and its score |

<summary><b>简体中文</b></summary>

Krino Matrix 致力于解放人的认知资源。

我们希望通过人工智能理解复杂状态、生成可行方案并评估行动价值，降低人们在信息处理、分析和决策上的认知负担，让每个人都能将有限的认知资源投入更有创造性、更有价值的事情中。

### 核心概念

| 模块 | 作用 |
| --- | --- |
| `State` | 描述当前状态 |
| `Generator` | 根据状态和目标生成候选行动 |
| `Evaluator` | 评估行动的价值 |
| `Decision` | 最终选择的行动及其得分 |
